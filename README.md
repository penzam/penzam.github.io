# PENZAM Consultancy — branded website

Designed to follow PENZAM Brand Guidelines v3 (November 2026).

## Publish to GitHub Pages
1. Extract the ZIP.
2. Upload **all files** directly into the root of `penzam/penzam.github.io` (not a subfolder).
3. Replace existing HTML, CSS and JS files; commit the changes.
4. Wait for GitHub Pages deployment and hard-refresh https://penzam.github.io/.

## Brand implementation
- Exact approved digital colours are defined in `style.css`.
- Headings specify Avenir Next; body specifies Calibri. These fonts must be installed on the viewer's system or approved licensed webfonts supplied. Fallbacks may render differently.
- `penzam-logo-reference.png` is a **temporary raster crop from the supplied brand-guidelines PDF**, not an approved production SVG. Replace it with the official outlined SVG master when available, and update the image `src` in each HTML page.
- The guidelines explicitly require an approved outlined SVG master and prohibit substituting screenshots for final artwork. This is therefore a preview / interim implementation pending the master.
- Verify `info@penzamconsultancy.com` exists before public launch.
- No invented biographies, client logos, portfolio claims or fabricated achievements have been included.
- This site uses no external dependencies or paid services.
